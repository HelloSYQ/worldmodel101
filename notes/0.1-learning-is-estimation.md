# Lesson 0.1: Learning is estimation

> Phase 0 · Week 1 · Lab: [`labs/phase0/lab01_learning_is_estimation.py`](../labs/phase0/lab01_learning_is_estimation.py)

**Main idea.** Training a neural network, including every world model in this course, is maximum-likelihood estimation. The model is very flexible and has no closed-form solution, so gradient descent finds the parameters. The linear-Gaussian special case is LS channel estimation, which you already know.

---

## 1. MLE gives you the loss function

A model is a parameterized distribution $p_\theta(y\mid x)$. Training chooses $\theta$ to maximize the likelihood of the data:

```math
\theta^\star=\arg\max_\theta\sum_{i=1}^{N}\log p_\theta(y_i\mid x_i)
=\arg\min_\theta\underbrace{\left(-\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(y_i\mid x_i)\right)}_{\mathcal{L}(\theta)\;=\;\text{"the loss"}}
```

Channel example:

```math
\mathbf{y}=\mathbf{X}\mathbf{h}+\mathbf{n},\quad \mathbf{n}\sim\mathcal{CN}(\mathbf{0},\sigma^2\mathbf{I})
\;\;\Rightarrow\;\;
-\log p(\mathbf{y}\mid\mathbf{h})=\frac{1}{\sigma^2}\|\mathbf{y}-\mathbf{X}\mathbf{h}\|^2+\text{const}
\;\;\Rightarrow\;\;
\hat{\mathbf{h}}_{\text{ML}}=(\mathbf{X}^H\mathbf{X})^{-1}\mathbf{X}^H\mathbf{y}
```

## 2. Every loss is a noise assumption

```math
\begin{aligned}
\text{Gaussian (fixed }\sigma\text{):}\quad & -\log p_\theta = \frac{\big(y-\mu_\theta(x)\big)^2}{2\sigma^2}+\text{const} && \Rightarrow\ \text{MSE}\\[4pt]
\text{Laplace:}\quad & -\log p_\theta = \frac{\big|y-\mu_\theta(x)\big|}{b}+\text{const} && \Rightarrow\ \text{L1}\\[4pt]
\text{Categorical:}\quad & -\log p_\theta(y=k\mid x) = -\log\frac{e^{z_k}}{\sum_j e^{z_j}},\;\; \mathbf{z}=f_\theta(x) && \Rightarrow\ \text{cross-entropy}\\[4pt]
\text{Gaussian (learned }\sigma\text{):}\quad & -\log p_\theta = \frac{\big(y-\mu_\theta(x)\big)^2}{2\sigma_\theta^2(x)}+\tfrac{1}{2}\log\sigma_\theta^2(x)+\text{const} && \Rightarrow\ \text{PETS-style loss (Phase 2)}
\end{aligned}
```

| Assumption | Loss | Optimal prediction |
|---|---|---|
| Gaussian, fixed $\sigma$ | MSE | the mean |
| Laplace | L1 | the median |
| Categorical (softmax) | cross-entropy | a full distribution over classes |
| Gaussian, learned $\sigma_\theta(x)$ | Gaussian NLL | the mean plus its own uncertainty |

BM-Case1 framed as classification over beam IDs is the cross-entropy row.

## 3. KL divergence, and why MLE minimizes it

```math
D_{\mathrm{KL}}(p\,\|\,q)=\mathbb{E}_{y\sim p}\!\left[\log\frac{p(y)}{q(y)}\right]\;\ge\;0,
\qquad =0 \iff p=q,
\qquad \text{not symmetric}
```

```math
\mathbb{E}_{p_{\text{data}}}\!\big[-\log p_\theta(y)\big]
=\underbrace{H(p_{\text{data}})}_{\text{independent of }\theta}
+D_{\mathrm{KL}}\!\big(p_{\text{data}}\,\|\,p_\theta\big)
```

So maximizing likelihood minimizes the **forward** KL; the left-hand side is the *cross-entropy*, hence the loss's name. The same quantities appear in Shannon theory:

```math
H(p)=-\mathbb{E}_{p}[\log p(y)],
\qquad
I(X;Y)=D_{\mathrm{KL}}\big(p(x,y)\,\|\,p(x)\,p(y)\big)
```

The two directions behave differently:

```math
\underbrace{D_{\mathrm{KL}}(p_{\text{data}}\,\|\,p_\theta)}_{\text{forward: spreads to cover every mode (MLE)}}
\qquad\text{vs.}\qquad
\underbrace{D_{\mathrm{KL}}(q_\phi\,\|\,p)}_{\text{reverse: locks onto one mode (VAE, Dreamer)}}
```

If $p_\theta$ is a single Gaussian and the data has two modes, forward KL forces the Gaussian to stretch across both.

## 4. MAP estimation is regularization

```math
\theta_{\text{MAP}}=\arg\min_\theta\left[-\sum_{i}\log p_\theta(y_i\mid x_i)-\log p(\theta)\right],
\qquad
p(\theta)=\mathcal{N}(\mathbf{0},\tau^2\mathbf{I})\;\Rightarrow\;-\log p(\theta)=\frac{\|\theta\|^2}{2\tau^2}+\text{const}
```

The Gaussian prior adds an $\ell_2$ penalty: *ridge regression* in statistics, *weight decay* in deep learning. For the channel with prior $\mathbf{h}\sim\mathcal{CN}(\mathbf{0},\sigma_h^2\mathbf{I})$:

```math
\hat{\mathbf{h}}_{\text{MAP}}=\left(\mathbf{X}^H\mathbf{X}+\frac{\sigma^2}{\sigma_h^2}\mathbf{I}\right)^{-1}\mathbf{X}^H\mathbf{y}=\hat{\mathbf{h}}_{\text{LMMSE}}
```

## 5. Gradient descent, and LMS as SGD

When there is no closed form:

```math
\theta_{k+1}=\theta_k-\eta\,\nabla_\theta\mathcal{L}(\theta_k)
```

For the channel (Wirtinger gradient):

```math
\mathcal{L}(\mathbf{h})=\frac{1}{N}\|\mathbf{y}-\mathbf{X}\mathbf{h}\|^2,
\qquad
\nabla_{\mathbf{h}^*}\mathcal{L}=-\frac{1}{N}\mathbf{X}^H(\mathbf{y}-\mathbf{X}\mathbf{h})
```

```math
\text{GD:}\quad \mathbf{h}_{k+1}=\mathbf{h}_k+\frac{\mu}{N}\mathbf{X}^H(\mathbf{y}-\mathbf{X}\mathbf{h}_k)
\qquad\qquad
\text{LMS:}\quad e_n=y_n-\mathbf{x}_n^T\mathbf{h}_k,\;\; \mathbf{h}_{k+1}=\mathbf{h}_k+\mu\,\mathbf{x}_n^{*}e_n
```

LMS is SGD with a batch size of 1. Stability and speed: each eigenmode of the error shrinks by $|1-\mu\lambda_i|$ per iteration, so

```math
\mathbf{R}=\frac{1}{N}\mathbf{X}^H\mathbf{X},\qquad
0<\mu<\frac{2}{\lambda_{\max}(\mathbf{R})},\qquad
\text{speed governed by } \kappa=\frac{\lambda_{\max}}{\lambda_{\min}}
```

A neural network replaces $\mathbf{X}\mathbf{h}$ with a nonlinear $f_\theta(x)$: the loss becomes non-convex with no closed form, so we need gradient descent plus automatic differentiation (Lesson 0.2).

## 6. The blur problem

```math
\arg\min_{c}\,\mathbb{E}\big[(Y-c)^2\big]=\mathbb{E}[Y],
\qquad
\arg\min_{c}\,\mathbb{E}\big[|Y-c|\big]=\operatorname{median}(Y)
```

```math
Y\in\{-1,+1\},\;\; P(Y=\pm1)=\tfrac12
\;\;\Rightarrow\;\;
\mathbb{E}[Y]=0,\quad \text{yet } P(Y=0)=0
```

The MSE-optimal prediction is a value the world never produces. A model avoids this only by learning the whole distribution $p(Y)$ rather than a single point estimate.

## 7. Why this matters for world models

A world model is a conditional density, and training it is MLE on trajectories:

```math
p_\theta(o_{t+1}\mid o_{\le t},a_t),
\qquad
\mathcal{L}(\theta)=-\frac{1}{|\mathcal{D}|}\sum_{\tau\in\mathcal{D}}\sum_{t}\log p_\theta(o_{t+1}\mid o_{\le t},a_t)
```

Almost every design choice in Phases 3–6 is a choice of
1. **which variable to model** (pixels, latents with reconstruction, latents without, task quantities only), and
2. **which distribution family to use**: a fixed-variance Gaussian gives MSE and blurry futures; stochastic latents (PlaNet, Dreamer), categorical tokens (IRIS, Genie) and diffusion (DIAMOND, GameNGen, Genie 3) all model $p(\text{future})$ instead of $\mathbb{E}[\text{future}]$.

## Lab 0.1 results

**A.1: three methods, one answer.** Closed-form LS, gradient descent and LMS all reach about −20.7 dB NMSE. GD matches LS to within $8\times10^{-17}$; LMS stays about $0.02$ away because single-sample gradients are noisy (why SGD training lowers its learning rate over time).

**A.2: step size and conditioning.**

| $\mu\,\lambda_{\max}$ | 0.5 | 1.0 | 1.9 | 2.1 |
|---|---|---|---|---|
| iterations to converge | 40 | 16 | 124 | diverges |

Correlated pilots raise $\kappa$ from 1.7 to 24.6 and slow convergence from 16 to 308 iterations. Neural networks have the same problem; Adam and normalization layers are the fixes.

**A.3: MLE vs MAP (NMSE, 2000 channels).**

| Pilots $N$ | SNR | LS (MLE) | MAP / LMMSE |
|---|---|---|---|

| 8 | 10 dB | −10.64 dB | −11.21 dB |

The prior helps a lot when data is scarce and stops mattering when there's plenty.
